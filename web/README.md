# Qazaq Loc QA

Локальное приложение для проверки качества переводов интерфейса в ARB-файлах Flutter. Оно сравнивает русский исходный текст с казахским или узбекским переводом, показывает находки и помогает безопасно подготовить отдельный исправленный файл. Эвристические и AI-предложения предназначены для проверки человеком, а не для автоматической публикации.

## Возможности

- Загрузка `.arb` и `.json` с ограничением до 10 МиБ на файл и до 20 файлов за один запрос. ARB-парсер сохраняет порядок и исходный текст строк, которые не изменялись.
- Анализ пар RU→KK и RU→UZ: пустые/непереведённые строки, совпадения с источником, placeholders, plural forms, длина, язык, термины и другие эвристические проверки. Всего зарегистрировано 11 категорий.
- Для находок отображаются ключ, исходная и текущая строка, категория, объяснение, уровень уверенности и, если доступно, предложение.
- Fix Engine позволяет принять, отклонить или вручную отредактировать значение. Перед применением проверяется сохранность placeholders.
- Применение сохраняет результат как отдельный `fixed_<имя-файла>` в каталоге uploads; исходная загруженная копия не перезаписывается.
- История применения и Undo. Резервная копия проверяется по SHA-256; состояние восстанавливается после перезапуска.
- Глоссарий русских терминов с целевой формой на казахском языке.
- AI Review — опциональная проверка выбранного количества строк через внешний или локальный LLM-провайдер; результаты можно принять, отклонить или заменить вручную.
- Статистика по находкам, решениям и уверенности.
- Экспорт отчёта в CSV, JSON, Markdown и Excel (`.xlsx`), а также скачивание ARB-результата.

### Категории локального анализа

| Категория | Что проверяет |
|---|---|
| `untranslated` | Пустое или отсутствующее значение перевода |
| `same_as_source` | Перевод совпадает с исходной строкой |
| `placeholder_mismatch` | Несовпадающие или потерянные placeholders |
| `plural_mismatch` | Возможное несоответствие plural-форм |
| `glossary_violation` | Для целевой локали `kk` — отклонение от заданного глоссария |
| `length_overflow` | Возможное чрезмерное увеличение длины |
| `machine_translation_suspect` | Эвристический признак машинного перевода |
| `inconsistent_term` | Непоследовательный перевод термина |
| `suffix_harmony` | Эвристическая проверка гармонии суффиксов |
| `orthography` | Проверки орфографии на основе правил и словарных данных |
| `wrong_language` | Вероятная строка на неподходящем языке |

Набор и точность эвристик зависят от текста и контекста. Наличие находки не доказывает ошибку, а отсутствие находок не является подтверждением качества перевода.
Глоссарий сейчас хранит казахское значение (`kk`); правило глоссария не применяется к целевым локалям вроде `uz`.

## Технологии

- Python и FastAPI для локального HTTP API.
- ARB/JSON и Pydantic-модели для файлов и запросов.
- Однофайловый HTML/JavaScript интерфейс в `backend/static/index.html`.
- `openpyxl` для экспорта Excel; `pytest` для тестов.
- Отдельная папка `frontend/` содержит React/Vite-проект, но текущий сервер его не собирает и не обслуживает: рабочий UI отдаётся из `backend/static/`.

## Требования

- Windows (BAT-скрипты), Linux или macOS для ручного запуска.
- Python 3.12 или новее — версия, указанная существующими `install.bat` и `start.bat`.
- Доступ к интернету нужен только для установки зависимостей и вызова облачного AI-провайдера. Локальный анализ не требует AI-ключей или сетевого доступа.
- Для Ollama дополнительно установите Ollama и скачайте выбранную модель.

## Установка

Откройте PowerShell или командную строку в корне проекта.

### Windows

1. Установите Python 3.12+ и включите Python в `PATH`.
2. Запустите `install.bat`. Скрипт устанавливает зависимости из корневого `requirements.txt` и создаёт каталоги `uploads` и `state`.
3. После завершения установки запустите `start.bat`.

### Ручная установка

```powershell
python -m pip install -r requirements.txt
```

Для разработки и запуска тестов те же зависимости включают `pytest`.

## Запуск и использование

Запустите `start.bat` на Windows либо выполните из корня проекта:

```powershell
python -m uvicorn qazaq_loc_qa.backend.api.main:app --host 127.0.0.1 --port 8000
```

Откройте в браузере:

- Интерфейс: <http://127.0.0.1:8000/ui>
- Swagger UI для API: <http://127.0.0.1:8000/docs>
- Корень API: <http://127.0.0.1:8000/>

Далее:

1. Загрузите ARB/JSON-файл(ы). Для сравнительного RU→KK или RU→UZ анализа загрузите исходный и целевой файлы.
2. В интерфейсе выберите исходный и целевой файлы. Автоматический выбор ориентируется на обозначения `ru`, `kk`, `kz`, `uz`, `en` в именах; при неоднозначности выберите файлы явно.
3. Запустите анализ. Просматривайте находки по категориям и уровням уверенности.
4. При необходимости отредактируйте предложение и примите/отклоните решение. Для ручной замены укажите новое значение.
5. Примените подготовленные решения. Результат записывается в отдельный файл с префиксом `fixed_`.
6. При ошибке применения нажмите Undo, чтобы восстановить предыдущую копию. Доступно отменить последнее применение.
7. Экспортируйте отчёт в нужный формат или скачайте подготовленный ARB-файл.

Для файла без пары анализаторы запускаются с пустым исходником, поэтому проверки, требующие сравнения с переводом, будут ограничены. Для полноценной языковой QA-проверки используйте исходный и целевой ARB вместе.

## AI Review

AI — дополнительная функция. Локальные анализаторы, Fix Engine, история и экспорты доступны без ключа и без AI.

### Поддерживаемые провайдеры

- OpenAI
- Google Gemini
- Anthropic
- OpenAI-compatible API (например, совместимые шлюзы)
- Ollama (локальный сервер по умолчанию `http://localhost:11434`)

### Настройка

1. В UI откройте раздел провайдеров AI и добавьте провайдера.
2. Выберите тип, укажите точный API model ID и при необходимости Base URL.
3. Для облачного сервиса задайте API-ключ: в форме провайдера либо через переменную окружения, имя которой указано в `api_key_env`.
4. Сохраните настройки и используйте кнопку проверки подключения. Проверка выполняет реальный короткий сетевой запрос к выбранному провайдеру.
5. После анализа откройте AI Review, выберите провайдера и задайте максимальное число строк (до 500), размер пакета (1–50) и, если нужно, лимит токенов. Запустите Review и следите за прогрессом, ошибками и расходом.

Ключи, сохранённые через UI, хранятся локально в `qazaq_loc_qa/backend/state/ai_secrets.json`; файл не зашифрован. Не публикуйте его, не добавляйте в систему контроля версий и ограничьте доступ к каталогу проекта. Для облачного API предпочтительнее переменная окружения. Стоимость — приблизительная оценка на основе цен, указанных в конфигурации провайдера; лимит токенов ограничивает job, но не гарантирует точный денежный потолок.

При AI Review исходные строки, текущие переводы и подходящие термины из глоссария отправляются выбранному провайдеру. До запуска убедитесь, что передача текста соответствует вашим требованиям конфиденциальности. AI не запускает код и не применяет изменения самостоятельно: предложения требуют решения пользователя и проходят проверку placeholders.
Текущий глоссарий содержит только казахские целевые формы и передаётся в AI Review только для локали `kk`; поддержка локализованных глоссариев для узбекского пока не реализована.

### Работа без AI

Не добавляйте провайдера и не запускайте AI Review. Основной анализ выполняется локально. Для Ollama облачный ключ не нужен, но локальный Ollama server и сама модель должны быть установлены и запущены.

## Структура проекта

```text
.
├── install.bat, start.bat       # Установка и запуск Windows
├── requirements.txt             # Python-зависимости
├── handout/                     # Примеры/входные ARB-файлы
├── qazaq_loc_qa/
│   ├── backend/
│   │   ├── api/                 # FastAPI endpoints и сохранение состояния
│   │   ├── analysis/            # Оркестратор 11 анализаторов
│   │   ├── analyzers/           # Базовые и языковые эвристики
│   │   ├── ai/                  # Провайдеры, AI Review, cache, настройки
│   │   ├── fixes/               # Проверка placeholders и Fix Engine
│   │   ├── glossary/            # Персистентный глоссарий
│   │   ├── utils/               # ARB parser и placeholders
│   │   ├── static/index.html    # UI, обслуживаемый FastAPI
│   │   ├── tests/               # Автоматические тесты
│   │   ├── state/               # Анализы, настройки AI, глоссарий, backups
│   │   └── uploads/             # Загруженные файлы и варианты fixed_*
│   ├── frontend/                # Отдельный React/Vite scaffold; не обслуживается API
└── docs/archive/                # Архив промежуточных отчётов и QA-артефактов
```

`state/` и `uploads/` создаются приложением/установщиком и содержат локальные данные. Включайте оба каталога в резервную копию, если нужно сохранить анализы, настройки, загруженные файлы и историю.

## HTTP API

Все маршруты доступны на `http://127.0.0.1:8000`. Методы ниже соответствуют текущему FastAPI-приложению; интерактивная схема с моделями запросов доступна на `/docs`.

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/` или `/ui` | Открыть web-интерфейс |
| `POST` | `/upload` | Загрузить ARB/JSON через multipart-поле `files` |
| `GET` | `/files` | Список загруженных файлов |
| `GET` | `/compare?file1=…&file2=…` | Сравнить наборы ключей двух файлов |
| `POST` | `/analyze` | Создать анализ; JSON принимает `file_ids` и необязательные `source_file_id`, `target_file_id`, `category_filter` |
| `GET` | `/analysis/{analysis_id}/errors` | Получить находки; поддерживаются query-фильтры `category`, `confidence` |
| `POST` | `/analysis/{analysis_id}/fixes` | Записать действия accept/reject/manual |
| `POST` | `/analysis/{analysis_id}/apply` | Применить принятые/ручные значения к целевому файлу |
| `POST` | `/analysis/{analysis_id}/undo` | Отменить последнее применение |
| `GET` | `/analysis/{analysis_id}/stats` | Статистика анализа и решений |
| `GET` | `/analysis/{analysis_id}/report` | Полное JSON-состояние отчёта, решений и истории |
| `GET` | `/analysis/{analysis_id}/export/json` | JSON-экспорт отчёта |
| `GET` | `/analysis/{analysis_id}/export/markdown` | Markdown-экспорт |
| `GET` | `/analysis/{analysis_id}/export/csv` | CSV-экспорт |
| `GET` | `/analysis/{analysis_id}/export/excel` | Excel-экспорт |
| `GET` | `/analysis/{analysis_id}/download/{file_id}` | Скачать ARB-результат (если исправления не применялись, исходную загруженную копию) |
| `GET` | `/ai/providers` | Список провайдеров без значений API-ключей |
| `POST` | `/ai/providers` | Создать/обновить настройки провайдера и, опционально, ключ |
| `DELETE` | `/ai/providers/{provider_id}` | Удалить провайдера и сохранённый ключ |
| `POST` | `/ai/providers/{provider_id}/test` | Проверить подключение к провайдеру |
| `POST` | `/analysis/{analysis_id}/ai/review` | Запустить AI Review |
| `GET` | `/ai/review/{job_id}` | Получить состояние job, прогресс, findings, ошибки и usage |
| `POST` | `/ai/review/{job_id}/stop` | Запросить остановку AI job |
| `GET` | `/analysis/{analysis_id}/ai/findings` | Получить AI-находки |
| `POST` | `/analysis/{analysis_id}/ai/findings/decision` | Сохранить решение по AI-находке |
| `GET` | `/ai/usage` | Получить сохранённую статистику AI usage |
| `GET` | `/glossary` | Получить глоссарий |
| `POST` | `/glossary` | Добавить/обновить термин |
| `DELETE` | `/glossary/{ru_term}` | Удалить термин по русскому ключу |

## Данные и безопасность

- Сервер запускается на `127.0.0.1`, а не на всех сетевых интерфейсах. Не меняйте bind host и не выставляйте приложение в интернет без отдельной настройки аутентификации и защиты: пользовательской аутентификации в текущем API нет.
- Загруженные данные хранятся в `qazaq_loc_qa/backend/uploads/`; состояние анализов и настройки — в `qazaq_loc_qa/backend/state/`. Сделайте резервную копию этих каталогов перед очисткой/переносом проекта.
- Для принятого исправления исходный загруженный файл сохраняется; новое содержимое записывается отдельно под `fixed_` в uploads. Оригиналы в `handout/` анализируются как входные примеры и автоматически не перезаписываются.
- Undo восстанавливает snapshot последнего применения и проверяет его SHA-256. Это не заменяет внешнюю резервную копию.
- API-ключи в `ai_secrets.json` хранятся локально без шифрования. Не передавайте этот файл третьим лицам.
- AI Review отправляет текст выбранному провайдеру только после явного запуска. Используйте локальный Ollama, если нельзя отправлять текст в облачный API.
- Ограничение загрузки — 10 МиБ на файл, не более 20 файлов за запрос; допустимые расширения `.arb` и `.json`.
- Эвристики могут ошибаться, особенно на коротких строках, именах, игровых терминах и контекстно-зависимых фразах. Согласуйте итог с носителем языка или профессиональным редактором.

## Тестирование

Из корня проекта запустите полный набор:

```powershell
python -m pytest qazaq_loc_qa/backend/tests -q
```

Тесты включают API/integration сценарии, ARB, анализаторы, AI-адаптеры (mock), Fix Engine, placeholders, экспорт, persistence и Undo. Для проверки конкретных провайдеров:

```powershell
python -m pytest qazaq_loc_qa/backend/tests/test_ai_providers.py qazaq_loc_qa/backend/tests/test_ai_review.py -q
```

Mock-тесты не проверяют доступность внешнего AI-сервиса и качество его переводов. Установщик `install.bat` обновляет pip и устанавливает зависимости; его не требуется повторно запускать для обычного тестирования.

## Решение проблем

| Симптом | Что проверить |
|---|---|
| `python` не найден | Установите Python 3.12+ с опцией добавления в `PATH`; откройте новую консоль. |
| `start.bat` сообщает об отсутствующих зависимостях | Из корня проекта запустите `install.bat`, затем снова `start.bat`. |
| Порт 8000 занят | Остановите приложение, использующее порт, или запустите Uvicorn вручную на другом порту и откройте соответствующий URL. |
| UI не открывается | Убедитесь, что окно сервера остаётся запущенным; откройте `/ui` на том же порту. |
| ARB не загружается | Проверьте расширение `.arb`/`.json`, UTF-8, корректность JSON/ARB и лимиты размера/числа файлов. |
| Анализ сравнивает не те файлы | Явно выберите исходный и целевой файл; автоматический выбор использует языковые метки в имени файла. |
| Нет находок | Проверьте выбранные файлы и направление языка. Эвристики не обнаруживают все семантические ошибки. |
| Исправление отклонено из-за placeholders | Сохраните исходные placeholders целиком, включая количество повторов. |
| Undo недоступен или сообщает об ошибке snapshot | Undo есть только после Apply; проверьте наличие файлов в `backend/state/backups/` и не удаляйте/не редактируйте их вручную. |
| AI Review показывает 401/403 | Проверьте тип провайдера, переменную окружения/ключ и права доступа, не публикуя секрет. |
| AI Review показывает 404 или ошибку модели | Проверьте Base URL и точный API model ID, поддерживаемый вашим провайдером. |
| AI Review показывает 429/5xx или invalid JSON | 429/5xx обычно означают ограничение частоты или временную недоступность сервиса; дождитесь и повторите с меньшим числом строк/пакетом. Некорректный формат ответа может пропустить пакет; проверьте показанные job errors. |
| AI Review не работает без интернета | Отключите AI Review либо настройте запущенный локальный Ollama. Локальные анализаторы работают отдельно. |
| Ошибка при восстановлении состояния | Не удаляйте `state/` или `uploads/`; проверьте файлы и резервные копии, сохраните копию перед ручным восстановлением. |
